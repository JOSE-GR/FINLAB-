# FINLAB+

Plataforma interactiva de educación financiera para jóvenes.

# Sobre el proyecto

FINLAB+ es un proyecto educativo desarrollado como parte
del Servicio Social de la Universidad del Valle de México.

Su objetivo es brindar conocimientos básicos de finanzas
personales a jóvenes de entre 15 y 18 años.

# Temas principales

- Finanzas personales
- Ahorro y presupuesto
- Crédito y tarjetas de crédito
- Intereses e inversión
- Seguridad financiera

# Tecnologías

HTML, CSS y JavaScript.
